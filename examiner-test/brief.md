# 출제위원 지침 (v2 · 2026-10-05)

이 문서는 출제위원 테스트에서 새 문제를 만들 때 쓰는 기준이다. 자동 출제(동기화 도우미 → Codex)와 AI 채팅 직접 요청이 같은 기준을 따른다. 일반 문제 등록·수정·태그 분류·오답 관리에는 읽지 않는다.

## 1. 목적

기출을 흉내 내는 문제가 아니라, **공식 시험범위 안에서 수험생이 예상하기 어려운 지점을 찾아 문제화**한다. 실제 출제위원이 범위 전체를 훑어 "이것까지 나온다고?" 싶은 문제를 꺼내는 방식을 재현한다. 억지로 어렵게 만들거나 범위를 벗어나지 않는다.

## 2. 수준 기준 — 낮추지 않는다

- 기준은 한국세무사회 전산회계 1급 **공식 평가범위(별표3)와 실제 기출의 판단 깊이**다.
- 학습자의 정답률, 체감 난이도, "쉽게 해 달라"는 이전 대화의 분위기에 맞춰 수준을 낮추지 않는다. 학습자가 틀리는 것은 이 테스트의 정상 결과다.
- 정의를 그대로 묻고 오답이 명백한 **교재 기본 예제 수준**은 실패로 본다. '정석 출제'도 기출과 같은 판단 깊이를 요구한다.
- 난도는 **판단 지점**으로 만든다. 조건 방향의 전환, 비슷한 개념의 경계, 예외규정, 범위 주변부, 잘못된 일반화를 유도하는 자료가 판단 지점이다.
- 계산 단계·숫자 크기·문장 길이를 늘려서 어렵게 만들지 않는다. 계산은 기출 수준으로, 많아야 두 단계다. 계산을 복잡하게 만드는 것과 출제위원답게 만드는 것은 다르다.

## 3. 범위와 기출 데이터의 쓰임

- **범위의 기준은 공식 평가범위다.** 기출 빈도는 범위를 제한하지 않는다. 기출 데이터는 무엇이 많이 나왔고 무엇이 오래 나오지 않았는지 판단하는 자료다.
- 이론 범위: 회계원리(당좌·재고자산, 유·무형자산, 유가증권, 부채, 자본금, 잉여금, 수익과 비용), 원가회계(원가의 개념, 요소별·부문별 원가계산, 개별·종합(단일, 공정별)원가계산), 세무회계(부가가치세법). 규정 문구는 "부가가치세법(과세표준과 세액)"이지만 실제 기출(103·104·123~127회)은 납세의무자·납세지·과세기간·사업자등록·공급과 공급시기·영세율과 면세·세금계산서·매입세액까지 출제했으므로 이 관찰 범위까지를 1급 부가가치세 범위로 본다.
- 실무 범위: 일반전표 입력, 매입·매출거래자료 입력(유형코드 26종 모두 범위 안).
- 같은 별표3에서 전산세무 등급에만 있는 항목(외화환산·회계변경·표준원가계산·법인세·소득세)은 1급 이론 문제로 내지 않는다.
- 분석 데이터: 이론 최근 표본 123~127회 75문항, 과거 표본 103·104회 30문항, 실무 123~126회 56문항. 105~122회는 분석하지 않았다. 따라서 "장기 미출제"는 언제나 **후보**로 쓰고 근거(예: "103회 출제, 123~127회 미관찰")를 함께 적는다.

## 4. 세트 구성 (출제위원 랜덤일 때)

한 세트에 아래를 섞는다. 사용자가 스타일을 골랐다면 고른 스타일을 우선하되 품질 기준은 같다.

1. 최근 자주 나온 핵심 개념을 **낯선 각도**로 묻는 문항
2. **장기 미출제 후보**: 과거 표본에서만 관찰됐거나 두 표본 모두에서 미관찰된 범위 내 개념, 또는 실무 표본에서 한 번도 나오지 않은 매입매출 유형코드
3. **교재 주변부 또는 예외규정**: 원칙 뒤에 붙은 제외·특례, 공식 교재의 작은 단서 조항
4. **함정형**: 비슷한 개념 두 개 이상을 섞어 경계를 판단하게 하는 문항
5. **"이것까지?"**: 범위 안의 세부 판단으로, 근거가 공식 교재·기준·법령에 있는 문항

- 이미 출제한 문제(요청에 목록 제공)와 같은 개념의 같은 판단 지점을 반복하지 않는다.
- 문항 수의 **두 배 후보를 먼저 구상**하고, 아래 품질 기준으로 걸러 최종 문항만 낸다. 걸러낸 이유는 selectionNote에 짧게 쓴다.

## 5. 이론 문항 형식

- 4지선다, 단일 정답. 오답 3개는 각각 근거로 반증할 수 있어야 한다.
- 시험 문장체를 쓴다("~으로 옳은 것은?", "~으로 옳지 않은 것은?", "~은 얼마인가?"). 기출의 부정형·긍정형·계산형 비율을 참고한다.
- 오답 선택지는 기출 방식으로 만든다: 개념 대체, 시점·기준 교체, 원칙의 과잉 일반화("항상·모두"), 포함 범위 오류, 제도 목적과 실제 의무의 혼동.
- 정답 선택지만 유독 길거나 구체적이지 않게 한다. 단정 표현("항상·반드시·모두")을 정답에 두지 않는다.
- 제목은 중립적인 사실로 쓴다. 정답·함정·스타일·"예외" 같은 단서를 제목과 지문에 노출하지 않는다.
- 자료가 필요하면 table(머리글·행)로 준다. 한 줄 문장으로 평탄화하지 않는다.

## 6. 실무(전표) 문항 형식

- KcLep 입력 기준이다. 일반전표: 차대·계정·금액·부문(판/제)·거래처(채권·채무 계정). 매입매출: 날짜·유형코드·공급가액·세액·공급처·전자 여부·분개 유형 + 분개 전체.
- 유형 14·17·22·57·61은 공급대가에서 공급가액과 세액을 나누고, 11·51·54는 공급가액의 10%가 세액이다.
- 54.불공은 불공제 사유, 카드 유형(17·18·19·57·58·59)은 카드사, 영세율 유형(12·16·19·24·52·59)은 영세율 구분을 해당 필드에 정답으로 둔다.
- 출제위원다운 실무 판단: 증빙 종류로 유형코드 결정(계산서·카드전표·현금영수증·수입세금계산서), 표본 미관찰 유형코드, 계정 판단 함정(자본적/수익적 지출, 미지급금/외상매입금, 예수금, 선급·선수 정산, 대손충당금 우선 사용), 부문 구분(제조/판관).
- 금액은 기출처럼 단순하게 둔다. 영수증·계산서처럼 표가 필요한 자료는 exhibit(머리글·행)로 준다.
- 분개 행은 6행 이하. 차변 합계와 대변 합계가 같아야 한다. 계정과목은 KcLep 표준 계정명을 쓴다. 매도가능증권은 178 계정이다.

## 7. 근거

- basis에 확인한 근거를 적는다(일반기업회계기준 장·문단, 부가가치세법 조문, 공식 교재, 관련 기출 ID).
- 표본 밖 개념의 이론 문항은 references에 실제로 확인한 HTTPS 주소를 넣는다. 법령은 `https://www.law.go.kr/법령/부가가치세법/제45조` 형식을 쓸 수 있다. 확인하지 못한 주소를 지어내지 않는다.
- 법령 문제는 오늘 날짜 기준 현행 조문으로 확인한다. 근거가 부족하거나 모순되면 그 문항은 내지 말고 withheld에 사유를 쓴다.

## 8. 자기 검토 (review, 9개 기준)

각 문항의 review에 아래 9개를 "통과/주의/해당 없음: 이유" 형식으로 적는다. AI의 1차 검토일 뿐 사람의 검증이나 실제 시험 적합성 인증이 아니다. 인증처럼 표현하지 않는다.

| 키 | 질문 |
|---|---|
| copy | 기존 기출을 거의 복사하지 않았는가? (관련 기출과 무엇이 다른가) |
| textbook | 평범한 교재형 연습문제 수준에 머물지 않는가? |
| sentence | 실제 시험처럼 문장이 자연스러운가? |
| choices | 선택지가 시험답게 구성되었는가? (각 오답의 반증 근거) |
| peripheral | 주변부 개념을 적절히 활용했는가? |
| absence | 최근 미출제 개념을 문제화했는가? (표본 근거) |
| exception | 예외규정을 활용했는가? |
| surprise | "이걸 여기서 물어본다고?" 싶은 판단 지점이 있는가? (계산량 증가와 구분) |
| forced | 억지스럽거나 시험범위를 벗어나지 않는가? |

"주의"가 2개 이상인 후보는 최종 세트에서 뺀다.

## 9. 금지

- 원문 전체·개인 기록·토큰을 요구하지 않는다.
- 기존 문제 ID·내용을 바꾸지 않는다.
- 결과는 지정된 JSON 형식만 반환한다.
