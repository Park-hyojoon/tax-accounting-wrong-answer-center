# 출제위원 테스트

## 공통 전표 입력기 (2026-10-05)

일반전표·매입매출전표는 기존 메뉴와 동일한 `../entry/` 입력기를 호출한다. `journal.js`는 문제 형식 변환·별도 기록·출제 근거 연결만 담당한다. 입력 화면/단축키/자동 분개/채점 수정은 `entry/README.md`의 파일 지도대로 한 곳에서 한다. 기존 테스트 문제와 이력은 그대로 유지한다.

## 사용 흐름

- 메뉴의 ‘출제위원 테스트’ → **문제 풀기**에서 이론·일반전표·매입매출 중 하나를 고르면 등록된 문제가 열린다. 새로 출제한 문제가 먼저 보인다.
- 새 문제는 **새 문제 출제하기 → 지금 출제하기** 한 번이면 된다. 분야별 문항 수(기본 2·2·2)와 출제 스타일을 고르고 누르면 PC 도우미가 Codex로 출제하고, 검수를 통과한 문제가 자동으로 추가된다. 보통 5~15분 걸리며 화면을 닫지 않아도 된다.
- 도우미가 꺼져 있거나 휴대폰이면 ‘채팅에 직접 부탁하기’의 한 문장을 AI 채팅에 보낸다.
- 결과는 다른 기기에서도 쓰도록 「동기화」를 한 번 누른다.

## 품질 관리 — 사용자가 점수를 매기지 않는다

1. **출제위원 지침(brief.md)**: 수준을 낮추지 않는다, 공식 평가범위가 기준이다, 계산량이 아니라 판단 지점으로 난도를 만든다, 9개 기준으로 자기 검토한다.
2. **후보 거르기**: 요청 수보다 분야마다 1개씩 더 내고(예비), 형식·세액·차대변·근거 링크 검사와 9개 기준 검토로 거른다.
3. **독립 재풀이**: 정답을 모르는 다른 Codex 대화가 풀어 정답이 일치하고 모호하지 않은 문항만 남긴다. 탈락한 후보와 이유는 ‘걸러진 후보’에 남는다.
4. **화면 최종 검사와 자동 점검**: 정답이 유독 긴 선택지, 정답의 단정 표현, 제목의 정답 누설, 세액 불일치, 유형코드 노출, 다른 문제와 겹치는 지문, 정답 번호 쏠림을 찾는다. 문제를 푼 뒤 ‘출제 근거와 난이도 점검’에서 9개 기준 검토표와 자동 점검을 볼 수 있다.
5. 이 점검은 AI의 1차 검토다. 사람의 검증이나 실제 시험 적합성 인증이 아니다.

## 분석 자료

- 이론: 최근 123~127회 75문항 + 과거 103·104회 30문항. 개념 49개(공식 평가범위 기반 추가 5개 포함). ‘이론 기출 분석과 출제 기준’에서 개념별 최근·과거 관찰, 테스트 출제 횟수, 오답 선택지 유형을 본다.
- 실무: 123~126회 일반전표·매입매출·오류수정 56문항. 매입매출 유형코드 26종 중 12종만 관찰되었고 14종은 표본 내 미관찰이다.
- 기출 빈도는 범위를 제한하지 않는다. 105~122회는 분석하지 않아 장기 미출제는 후보로만 표시한다.

## 연결과 기록 보존

- 일반 훈련센터는 링크만 제공한다. 전용 화면에서 문제를 열 때만 분석·문제 데이터를 읽는다.
- API 키·별도 서버·추가 라이브러리를 쓰지 않는다. 자동 출제는 PC에 설치된 Codex와 로그인된 ChatGPT 계정을 쓰며, 사용 한도는 그 계정을 따른다.
- 기존 훈련 상태·통계·동기화와 분리된 `exam-20260914-examiner-test-v1`(이론)·`exam-20260914-examiner-journal-v1`(전표) 키에 기록한다.
- 공개 묶음의 ID·내용은 불변이다. 이론과 전표의 테스트 기록은 각각 백업·복원으로 옮긴다.
- 지침·구조는 MODE.md, 수준과 출제 기준은 brief.md를 본다.
