# 출제위원 테스트 - 작은 독립 실험

## 연결과 격리
- 홈에는 별도 페이지로 가는 링크 한 개만 추가한다. 기존 메뉴 정렬·문제 배열·학습 상태·채점·동기화 코드는 수정하지 않는다.
- examiner-test/index.html은 전용 화면이다. 모드 시작을 눌러야 analysis.js와 questions.js를 읽는다.
- 서버/API 키/외부 AI 호출은 없다. 준비된 AI 시범 6문항은 정적 문제이며 선택/조합은 새로운 AI 생성이 아니다.
- 실제 재출제는 선택 조건과 압축된 분석/범위 목록을 내보내어 AI에게 요청한 뒤 JSON을 가져오는 수동 연결 방식이다. 생성 요청과 검토/채점 과정을 분리한다.
- 테스트의 답변/평가는 exam-20260914-examiner-test-v1 키 하나에만 저장한다. 기존 상태 키, 원격 상태, 직접 오답 원장 및 전체 훈련 통계와 연결하지 않는다.
- 테스트 기록은 JSON 백업/복원으로만 옮긴다. 현재 동기화 기능에 포함되지 않는다.
- 최초 시험 범위는 이론 4지선다이다. 연속 5회(123~127회)의 이론 75문항을 구조화한다. 기존 전표 훈련은 그대로 유지한다.
- 5회분 표본으로 장기 미출제·출제확률·교재 중요도를 추정하여 단정하지 않는다. 미관찰 개념은 범위 내 후보이며 공식 교재/기준/법령 근거가 있어야 생성한다.
- 개인 원문은 private/에만 저장한다. 공개 분석은 원문을 복제하지 않는 개념 요약이다.

## 품질 확인
- 문제마다 개념/범위 근거, 출제 의도, 함정, 기출과의 차이, 계산 부담, AI의 자체 검토와 사용자의 평가를 구분한다.
- 9개 평가 항목은 복제성, 교재형 단순성, 문장, 선택지, 주변부 활용, 표본 미출제 활용, 예외, 뜻밖의 판단 지점, 범위/억지 여부다.
- 객관적 형식 검사는 JSON/4선택지/정답 범위/ID/스타일/근거 URL/개념 연결/중복 등을 검사할 뿐 회계 정답과 출제 적절성을 인증하지 않는다.
- 가져온 문제는 미검토 상태로 대기한다. 내용을 확인하고 사용할 때만 시범 문제에 추가한다. 기존 6문항은 보존하고 한 번의 테스트는 최대 8문항이다.
- 분석에는 정답/해설 요약, 출제 포인트, 함정, 문장/선택지 유형을 저장한다. 원문이나 긴 분석을 다시 읽지 않고 요청에 필요한 압축 정보를 사용한다.
- 시험 범위 목록은 관측 기출의 개념 목록과 별도다. 빈도는 해당 표본에 실제 매핑한 문항수/회차수이다. 후보 목록은 전체 세부 범위를 인증하는 완성형 목록이 아니다.
- Anki 간격 반복은 미구현이다.
