# 출제위원 테스트

## 사용 흐름

- 상단 메뉴의 ‘출제위원 테스트’에서 들어와 ‘문제 풀기’를 누르면 이론·일반전표·매입매출전표 중 하나를 고른다.
- ‘문제 풀기’는 이미 등록된 문항을 연다. 이론은 최초 시범 6문항과 새 묶음, 일반전표·매입매출은 각각 준비된 2문항을 제공한다. 새 출제 버튼과 기능을 구분해 설명한다.
- 새 출제는 이 작업 폴더에 접근하는 AI 채팅에 ‘출제위원 새 문제 6개를 이론·일반전표·매입매출에서 2개씩 만들어 테스트에 추가해 주세요’라고 요청한다. AI는 MODE.md에 따라 검토·등록·배포한다.
- 웹 버튼은 채팅으로 자동 전송하거나 AI를 호출하지 않는다. 화면에서 요청 장소와 보내야 할 한 문장을 안내한다.
- 기본 6문항은 세 분야에서 2개씩 만든다. 질문 방향 바꾸기, 비슷한 개념 구분하기, 세부개념·예외 활용하기를 배분하고 기출 수준의 지식·문장·계산량을 유지한다.
- 새 이론 문제는 library.js, 새 전표 문제는 journal-bank.js에 추가한다. 사용자가 JSON을 가져올 필요가 없다. 다른 AI를 이용하는 이론용 상세 요청·파일 가져오기는 접힌 고급 기능으로 보존한다.
- 개인의 ‘출제위원다운가’ 평가는 화면에서 묻지 않는다. 기존 평가 이력은 보존한다. 출제 근거와 난이도 점검은 정답·해설 뒤에 표시한다.

## 연결과 기록 보존

- 일반 훈련센터는 링크만 제공한다. 전용 화면에서 문제 또는 고급 자료를 열 때만 분석·문제 데이터를 읽는다.
- 서버·API 키·외부 AI 호출·추가 라이브러리를 사용하지 않는다.
- 기존 훈련 상태·통계·동기화와 분리된 exam-20260914-examiner-test-v1 키를 그대로 사용하고 전표 연습은 exam-20260914-examiner-journal-v1 키에 따로 저장한다.
- 공개 묶음은 처음 풀 때 문제 사본과 새 풀이 회차를 한 번에 저장한다. 이후 공개 목록에서 빠져도 기존 기록을 열고 백업·복원할 수 있다.
- 공개 문제의 ID·내용은 불변이다. 같은 ID의 다른 내용이 발견되면 기존 기록을 보존하고 열기를 중단한다.
- 이론과 전표의 테스트 기록은 각각 명시적인 백업·복원으로 다른 기기에 옮길 수 있다. 기존 원격 학습 동기화에는 포함하지 않는다.
- 이전 문제·스타일 필터·분석표·수동 가져오기·기록 보관은 ‘이전 문제·설정·분석 보기’에 보존한다.

## 분석과 품질의 경계

- 123~127회 이론 75문항을 한 번 구조화했다. 실무 출제 빈도 분석은 하지 않았고 전표 문항은 해당 회차 확정답안의 처리 기준으로 별도 검토했다.
- 기출 빈도는 범위를 제한하지 않는다. 별도 개념 후보 목록을 확장할 수 있으며, 전체 교재 세부목차를 인증한 목록은 아니다.
- 표본 내 미관찰을 최근 수년의 장기 미출제·출제 확률·낮은 중요도로 단정하지 않는다.
- 원문은 private/에만 보관한다. 출제는 압축된 개념·정답·해설·빈도·출제 포인트를 사용한다.
- 형식 검사는 회계 정답이나 시험 적절성을 인증하지 않는다. 난도는 실제 기출의 처리 범위·문장 길이·계산 단계와 비교한다. 제공된 123~127회 후기 요약은 참고 의견이며 검증된 대중 평점이나 128회 평가로 제시하지 않는다.
- Anki 간격 반복은 이번 범위에 포함하지 않는다.
