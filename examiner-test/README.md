# 출제위원 테스트

## 사용 흐름

- 첫 화면은 ‘문제 풀기’와 ‘새 문제 부탁하기’ 두 동작이다. 기본 조건을 고를 필요가 없다.
- ‘문제 풀기’는 최신 공개 묶음을 연다. 해당 묶음의 풀이 기록이 있으면 이어서 연다. 신규 묶음이 없으면 최초 시범 6문항을 연다.
- 새 출제는 이 작업 폴더에 접근하는 AI 채팅에 ‘출제위원 문제 6개 만들어서 테스트에 추가해 주세요’라고 요청한다. AI는 MODE.md의 기본 조건에 따라 출제·검토·등록·배포까지 수행한다.
- 웹 버튼은 채팅으로 자동 전송하거나 AI를 호출하지 않는다. 화면에서 요청 장소와 보내야 할 한 문장을 안내한다.
- 기본 구성은 질문 방향 바꾸기 2개, 비슷한 개념 구분하기 2개, 범위 내 세부개념·예외 2개다. 기출 수준의 지식·문장·계산량으로 만든다.
- 새 문제는 library.js에 추가한다. 사용자가 JSON을 가져올 필요가 없다. 다른 AI를 이용하는 상세 요청·파일 가져오기는 접힌 고급 기능으로 보존한다.
- 정답 아래에서 ‘낯설지만 납득돼요 / 이미 익숙해요 / 억지스럽거나 범위가 의심돼요’ 중 하나로 의견을 남길 수 있다. 기존 9개 항목 상세 평가도 유지한다.

## 연결과 기록 보존

- 일반 훈련센터는 링크만 제공한다. 전용 화면에서 문제 또는 고급 자료를 열 때만 분석·문제 데이터를 읽는다.
- 서버·API 키·외부 AI 호출·추가 라이브러리를 사용하지 않는다.
- 기존 훈련 상태·통계·동기화와 분리된 exam-20260914-examiner-test-v1 키를 그대로 사용한다.
- 공개 묶음은 처음 풀 때 문제 사본과 새 풀이 회차를 한 번에 저장한다. 이후 공개 목록에서 빠져도 기존 기록을 열고 백업·복원할 수 있다.
- 공개 문제의 ID·내용은 불변이다. 같은 ID의 다른 내용이 발견되면 기존 기록을 보존하고 열기를 중단한다.
- 테스트 기록의 다른 기기 이동은 명시적인 백업·복원으로 한다. 기존 원격 학습 동기화에는 포함하지 않는다.
- 이전 문제·스타일 필터·분석표·수동 가져오기·기록 보관은 ‘이전 문제·설정·분석 보기’에 보존한다.

## 분석과 품질의 경계

- 123~127회 이론 75문항을 한 번 구조화했다. 실무는 이번 표본에 포함하지 않는다.
- 기출 빈도는 범위를 제한하지 않는다. 별도 개념 후보 목록을 확장할 수 있으며, 전체 교재 세부목차를 인증한 목록은 아니다.
- 표본 내 미관찰을 최근 수년의 장기 미출제·출제 확률·낮은 중요도로 단정하지 않는다.
- 원문은 private/에만 보관한다. 출제는 압축된 개념·정답·해설·빈도·출제 포인트를 사용한다.
- 형식 검사는 회계 정답이나 시험 적절성을 인증하지 않는다. AI의 근거 검토와 사용자의 품질 평가를 구분한다.
- Anki 간격 반복은 이번 범위에 포함하지 않는다.
