# 출제위원 테스트를 명시적으로 요청한 경우만 읽기

일반 등록·수정·태그 분류·오답 관리에는 이 문서, analysis.js, private/ 원문을 읽지 않는다.

## 좁은 진입점

1. 요청이 출제위원 테스트/출제위원 모드인지 확인한다.
2. examiner-test/README.md와 이 문서의 기본 출제 조건을 적용한다. 사용자는 ‘출제위원 새 문제 6개를 이론·일반전표·매입매출에서 2개씩 만들어 테스트에 추가해 주세요’ 한 문장만 보내면 된다. 스타일 선택·긴 요청문·JSON 전달을 사용자에게 요구하지 않는다.
3. analysis.js는 최초 분석 때 만든 요약이다. 원문을 매번 다시 읽지 않는다. private/theory-index.json은 근거가 불충분한 해당 문항을 감사해야 할 때만 읽는다.
4. 기본은 6문항(이론 2, 일반전표 2, 매입매출전표 2)이다. 이론은 examiner-test/library.js의 ExaminerLibrary 배열, 전표는 examiner-test/journal-bank.js의 ExaminerJournalBank 배열 끝에 추가한다. 기존 ID·내용은 바꾸지 않는다. 기존 data/*.js, META, 오답 원장에는 넣지 않는다. 사용자는 완료 후 새로고침하고 ‘문제 풀기’에서 분야를 고른다. 다른 AI 결과의 수동 가져오기는 고급 기능으로만 남긴다.
5. 기출 빈도와 시험범위를 별개로 본다. 후보 목록 밖 개념도 금지된 것은 아니지만, 먼저 공식 교재·기준·법령의 범위 근거를 확인한 뒤 개념 목록 확장을 제안한다.
6. 123~127회 이론 75문항 표본으로 실무 포함 전체 빈도·최근 수년 장기 미출제·출제 확률·사용자 교재 중요도를 단정하지 않는다. 실무 문제는 공개된 확정답안의 처리와 채점 항목을 따로 확인한다. 관찰되지 않은 개념은 미관찰 후보로 표시한다.
7. 숫자만 교체하지 말고 원칙의 적용 방향, 개념 결합, 예외의 경계를 바꾼다. 계산 부담을 올려 난이도를 꾸미지 않는다.
8. 단일정답·선택지별 반증·자연스러운 문장·근거·범위를 검토한다. AI의 검토를 인간 검토나 실제 시험 적합성 인증으로 표현하지 않는다.
9. 법령 문제는 현행 시행일을 확인한다. 모순이나 근거 부족이 있으면 해당 문항은 출제 보류한다.
10. 문제 바로 아래에서 채점하고 접힌 정답을 확인한다. 자료표는 table 구조로 유지한다. 제목과 풀이 전 화면에서 정답이나 결정적인 함정을 누설하지 않는다.

## 이번 시범의 경계

- 기본 6문항은 이론·일반전표·매입매출전표 각 2개다. 세 분야에 질문 방향 바꾸기, 비슷한 개념 구분하기, 범위 내 세부개념·예외 활용하기를 무리 없이 배분한다. 스타일은 보조 분류다.
- 목표는 ‘낯설지만 배운 내용으로 풀 수 있는가’다. 기출은 지식 수준·문장 길이·계산량의 기준이다. 정답·출제 의도·함정·기출과의 차이는 풀이 전 화면에 노출하지 않는다.
- 사용자가 출제를 요청하면 생성→근거·단일정답 검토→등록→검사→일반 배포까지 이어서 처리한다. 이 작업 폴더의 AI가 등록을 담당하므로 사용자에게 같은 요청을 다시 보내거나 JSON을 옮기라고 하지 않는다.
- 이론 묶음은 engine.js의 validatePack, 전표 묶음은 journal.js의 validateBank와 채점 검사로 확인한다. 각각의 데이터 파일 로딩 버전과 program-version.json을 갱신한다. 기록과 개인 원문은 공개하지 않는다.
- 공개 묶음은 사용자가 처음 풀 때 사본을 테스트 기록에 함께 저장한다. 이후 공개 목록이 바뀌어도 저장된 묶음과 이전 풀이를 보존한다. 기존 ID의 내용을 바꾸지 않는다.
- 사용자가 제공한 난도 후기 파일에는 123~127회 서술 요약만 있다. ‘대중의 검증된 점수’나 128회 평가로 간주하지 않는다. 난이도는 해당 분야의 기출 처리 범위, 단일 정답, 문장 길이, 계산 단계, 추가 지식 여부로 먼저 점검하고 후기 경향은 보조로 사용한다. 학습자 개인의 ‘출제위원다운가’ 점수는 출제 기준에 반영하지 않는다.

- 최초 시범 6개는 이 대화의 AI가 출제한 정적 검토본이다. ‘문제 풀기’는 가장 최근에 추가한 묶음 또는 풀던 회차를 연다. 실시간 AI 생성 버튼이 아니다.
- API 키·서버·외부 모델 호출·빌드 도구·UI 라이브러리를 추가하지 않았다.
- 사용자 승인 후 가져온 묶음은 시험 정답 인증이 아니라 이 실험에서 사용하겠다는 승인이다.
- 테스트의 기록은 별도 브라우저 저장 및 명시적 백업/복원만 한다. 기존 동기화에는 포함하지 않는다.
- Anki/FSRS 간격 반복은 이번 범위가 아니다.
