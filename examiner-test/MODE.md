# 출제위원 테스트를 명시적으로 요청한 경우만 읽기

일반 등록·수정·태그 분류·오답 관리에는 이 문서, brief.md, analysis.js, practice-analysis.js, private/ 원문을 읽지 않는다.

## 두 가지 출제 경로 — 같은 지침(brief.md)과 같은 검사를 쓴다

1. **바로 출제(기본, 사용자는 버튼 하나)**: 출제위원 테스트 화면의 「새 문제 출제하기 → 지금 출제하기」. PC 동기화 도우미(`sync-helper.py` v3)가 설치된 Codex(ChatGPT 계정)를 비대화형으로 실행한다. 유료 API 키를 쓰지 않는다. 사용자가 AI 채팅으로 이동하거나 요청문·JSON을 옮길 필요가 없다.
   - ① Codex가 `brief.md`와 압축된 기출 분석으로 후보(분야마다 예비 1개 포함)를 구상하고 9개 기준으로 걸러 출제한다.
   - ② 도우미가 형식·세액·차대변·근거 링크를 검사한다.
   - ③ **정답을 모르는 다른 Codex 대화**가 문항을 독립적으로 풀어, 정답이 일치하고 모호하지 않다고 한 문항만 남긴다.
   - ④ 화면이 engine.js·journal.js의 검사와 자동 점검(lint)을 다시 하고, 통과하면 `library.js`(이론)·`journal-library.js`(전표) 끝에 덧붙인다. 자동 점검에서 '주의'가 나오면 사용자가 보고 추가 여부를 정한다.
   - 도우미가 꺼져 있거나(휴대폰·https 화면) Codex가 없으면 화면이 수동 문장 복사를 안내한다.
2. **AI 채팅 직접 요청(수동/대체)**: 사용자가 ‘출제위원 새 문제 6개를 이론·일반전표·매입매출에서 2개씩 만들어 테스트에 추가해 주세요’라고 보내면 이 폴더의 AI가 brief.md를 읽고 같은 기준으로 출제한다. 이론은 `library.js`의 `ExaminerLibrary` 배열 끝, 전표는 `journal-library.js`의 `ExaminerJournalLibrary` 배열 끝(묶음 `{id,label,createdAt,items:[…]}`)에 추가한다. 시범 문항(`questions.js`, `journal-bank.js`)과 기존 ID·내용은 바꾸지 않는다.

## 수준과 범위

- 수준을 낮추지 않는다. 기준은 공식 평가범위(한국세무사회 별표3)와 실제 기출의 판단 깊이다. 학습자의 정답률·체감 난이도에 맞춰 쉽게 만들지 않는다. 교재 기본 예제 수준은 실패로 본다. (brief.md 2장)
- 기출 빈도는 범위를 제한하지 않는다. 범위는 공식 평가범위다. 분석 표본은 이론 123~127회 75문항 + 103·104회 30문항, 실무 123~126회 56문항이다. 105~122회는 분석하지 않았으므로 "장기 미출제"는 후보로만 쓰고 근거를 함께 적는다.
- 계산량으로 난도를 올리지 않는다. 판단 지점(방향 전환, 개념 경계, 예외, 주변부)으로 만든다.
- 개인의 ‘출제위원다운가’ 평점은 화면에서 묻지 않고 출제 기준에도 쓰지 않는다. 품질 점검은 9개 기준 AI 검토표(review), 자동 점검(lint), 독립 재풀이로 한다. 이 점검은 사람의 검증이나 실제 시험 적합성 인증이 아니다.
- 법령 문제는 현행 시행일을 확인한다. 모순이나 근거 부족이 있으면 그 문항은 내지 않는다(withheld).

## 데이터 파일

| 파일 | 내용 | 갱신 |
|---|---|---|
| `brief.md` | 출제위원 지침 v2(수준·범위·세트 구성·형식·검토 9기준) | 지침을 바꿀 때 |
| `analysis.js` | 이론 기출 요약(최근 5회 + 과거 2회, 개념 49개, 공식 범위) | 일회성 분석 |
| `practice-analysis.js` | 실무 기출 요약(유형코드 26종 빈도, 계정 기반 개념) | 일회성 분석 |
| `questions.js`, `journal-bank.js` | 시범 문항(불변) | 바꾸지 않음 |
| `library.js`, `journal-library.js` | 새로 출제한 묶음 | 출제할 때마다 끝에 추가 |
| `private/` | 원문·AI 작업 파일(공개 저장소 제외) | 도우미가 사용 |

## 경계

- 전표 입력·채점은 `../entry/`의 공통 입력기를 호출한다. 출제 지침/AI 처리/테스트 기록 연결은 `journal.js`에, 입력 화면/키보드/자동 분개/정답 판정은 공통 입력기에 둔다. 일반 메뉴에는 출제위원 분석 데이터를 불러오지 않는다. 수정 지도는 `../entry/README.md`를 참조한다.

- 서버·API 키·빌드 도구·UI 라이브러리를 추가하지 않았다. 도우미는 127.0.0.1에서만 받고 허용된 출처(file, localhost, 공개 화면)만 처리한다.
- 테스트의 기록은 별도 브라우저 저장(`exam-20260914-examiner-test-v1`, `…-examiner-journal-v1`)과 명시적 백업/복원만 한다. 기존 동기화·오답 원장·통계에는 합치지 않는다.
- 공개 묶음은 사용자가 처음 풀 때 사본을 테스트 기록에 함께 저장한다. 이후 목록이 바뀌어도 이전 풀이를 보존한다. 같은 ID의 다른 내용이 발견되면 기존 기록을 보존하고 열기를 중단한다.
- 새 문제가 다른 기기에도 보이게 하려면 화면의 「동기화」를 누른다(library 파일이 일반 push된다).
- Anki/FSRS 간격 반복은 이번 범위가 아니다.
