학습 센터 디자인 기준

컨셉은 English Basket입니다. 크림 바탕, 딥그린, 민트, 왼쪽 사이드바. 다음 디자인 변경 때 이 문서와 design/theme.css 하나만 보면 바로 작업할 수 있게 정리했습니다.

0. 빠른 시작 (인수인계 요약)

처음 맡은 사람은 이 칸만 읽고 시작해도 됩니다.

  1. 디자인은 design/theme.css 한 파일이 결정합니다. 색·글꼴·크기는 맨 위 :root의 --ui-* 토큰만 바꾸면 전체에 반영됩니다.
  2. 메뉴 뼈대(브랜드·아래 버튼·날짜/제목)는 training-ui.js가 만듭니다. 모양은 theme.css가, 요소 생성은 JS가 맡습니다.
  3. theme.css는 항상 마지막에 적용됩니다. training-ui.js가 <head> 맨 끝으로 옮깁니다. 그래서 대부분 규칙에 !important가 붙어 있습니다(옛 season.css가 !important를 많이 쓰기 때문).
  4. 수정 후 버전 올리기: theme.css를 고쳤으면 모든 페이지의 design/theme.css?v=N을 하나 올립니다(13장의 명령 참고). training-ui.js를 고쳤으면 training-tool.cmd bump training-ui.js 후 개념_정리.html, 약점_분석_임시.html도 같은 번호로 맞춥니다.
  5. 바꾸면 안 되는 곳: KcLep 입력 화면 재현(.kclep-shell), 영수증·계산서 재현(.exhibit*), 문제 표시 색(.qm-*). 12장 참고.

1. 컨셉: English Basket

원본: D:\00. 학습센터\02. English\public\style.css (English Basket 앱). 그 분위기를 회계 훈련 화면에 옮겼습니다.

따뜻하고 차분하게
순백 대신 크림(#f8f6ef) 바탕, 검정 대신 짙은 숲색 글자(#263f36). 오래 공부해도 눈이 편한 톤.
한 가지 주인공 색
딥그린(#276451)만 주 버튼·활성 메뉴·진행 막대에 씁니다. 나머지는 민트·크림의 옅은 면으로 위계를 만듭니다.
둥글고 가볍게
카드 21px, 버튼 14px 모서리. 그림자 없이 얇은 선(1px). 버튼은 올리면 2px 떠오릅니다.

디자인 원칙

  • 메뉴는 왼쪽, 본문은 가운데. PC에서는 왼쪽 고정 사이드바(236px), 모바일은 위쪽 얇은 막대 + ☰ 메뉴.
  • 정답·오답 색은 채점에만. 초록(--ui-ok)·테라코타(--ui-bad)는 채점 결과·위험 버튼에만 씁니다.
  • 분야 색은 아이콘과 띠에만. 이론=보라, 일반전표=청록, 매입매출=황토. 면 전체를 칠하지 않습니다.
  • 강조는 골드 안내 상자. 주의·안내 문구는 --ui-gold-soft 바탕 + --ui-gold-ink 글자.
  • 문구는 짧게. 디자인 변경 때 화면 설명문을 늘리지 않습니다.
예전 디자인 안내(D:\00. 학습센터\Design Guide Line Claude\디자인_시스템_가이드.md, "청록+골드 코인")는 지금 화면에 쓰이지 않는 이전 컨셉입니다. 현재 기준은 이 문서입니다.

3. 적용 순서 (왜 theme.css가 이기는가)

같은 대상에 여러 스타일이 겹칩니다. 나중에 적용된 것이 이깁니다.

① 페이지 <style>            (HTML 안, 가장 먼저)
② design/theme.css         (HTML <head> 끝에 <link>로 연결)
③ season.css               (season-ui.js가 실행 중에 추가)
④ JS 스타일들               (training-ui·weakness-center·account-search …)
⑤ design/theme.css  ← training-ui.js가 <head> 맨 끝으로 다시 옮김 (MutationObserver로 계속 유지)
  • training-ui.js가 없는 페이지(AI_작업규칙.html, examiner-test/index.html)는 ②만으로 충분합니다(뒤에 덮어쓰는 스타일이 없음).
  • JS가 요소에 직접 넣은 색(예: 유형 태그 TOP 10의 style="background…")도 theme.css의 !important가 이깁니다.
  • CSS 변수는 :root에서 다시 정의합니다. 페이지마다 다르던 옛 변수(--blue, --navy, --sky …)도 theme.css 1장에서 새 토큰에 연결했습니다.

본문 위쪽 머리말

  • 날짜 + 제목(.page-head): h1이 없는 화면(이론·일반전표·매입매출)에 training-ui.js가 <main> 맨 앞에 넣습니다. 제목은 현재 메뉴 이름입니다.
  • 민트 머리말 카드(.hero): 홈과 약점 분석. 홈은 <main> 밖에 있으므로 theme.css가 본문과 같은 폭으로 맞춥니다. 홈 머리말 높이는 85px 미만을 유지합니다(tests/compact-notebook.cjs가 검사).
상단 메뉴 높이를 쓰던 고정 위치 값(--nav-h, --concept-nav-height)은 PC에서 0으로 고정했습니다. 사이드바는 위쪽을 차지하지 않기 때문입니다. 메뉴를 다시 위로 올리면 이 줄을 지워야 합니다(13장 참고).
