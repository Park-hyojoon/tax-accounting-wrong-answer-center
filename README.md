# 전산회계 1급 오답 훈련센터

전산회계 1급 시험에서 틀린 문제를 다시 훈련하기 위한 개인 학습용 웹페이지입니다.

## 버튼 하나로 동기화

다섯 화면 모두 메뉴 오른쪽에 「🔄 동기화」 버튼이 있습니다. 한 번 누르면 아래를 순서대로 처리하고 최신 화면으로 새로고침합니다.

1. PC에 새로 추가된 문제·프로그램을 GitHub에 올립니다. GitHub에 더 최신 파일이 있으면 PC로 받습니다. (PC에서만)
2. PC·모바일의 학습기록(통과, 오답 횟수, 답변 이력)을 합쳐 GitHub에 저장합니다. 한쪽 기록을 덮어쓰지 않고 양쪽의 고유 이력을 모두 보존합니다.
3. 최신 화면으로 새로고침합니다.

## PC에서 사용하기

- PC 로그인 시 동기화 도우미(`sync-helper.py`)가 보이지 않게 자동 실행됩니다. 훈련센터에서는 「동기화」만 누르면 됩니다.
- PC에서는 토큰이 필요 없습니다. PC에 저장된 GitHub 로그인을 도우미가 그대로 사용합니다.
- 도우미가 일시적으로 준비되지 않으면 잠시 후 다시 누르거나 PC에 다시 로그인하면 자동으로 복구됩니다.
- 도우미는 내 PC 안(127.0.0.1:8790)에서만 요청을 받으며 외부에서는 접근할 수 없습니다.

## 모바일에서 사용하기

1. [오답 훈련센터 열기](https://park-hyojoon.github.io/tax-accounting-wrong-answer-center/)
2. 처음 한 번만 홈 아래쪽 「GitHub 연결」에 토큰을 넣고 「연결」을 누릅니다. 「이 기기에 토큰 기억하기」가 켜져 있으면 다음부터 다시 넣지 않아도 됩니다.
3. 그 뒤로는 어느 화면에서든 「🔄 동기화」 한 번이면 됩니다.

PC에서 올린 새 문제는 GitHub Pages가 반영하는 데 1~2분 정도 걸릴 수 있습니다.

## 처음 한 번 토큰 만들기 (모바일용)

[Fine-grained 토큰 만들기](https://github.com/settings/personal-access-tokens/new)에서 Selected repositories로 `Park-hyojoon/tax-accounting-learning-sync` 저장소만 선택하고 저장소 권한은 `Contents: Read and write`만 허용합니다. 토큰은 채팅에 보내거나 파일에 적지 말고 훈련센터 홈의 토큰 입력칸에만 넣으세요. 「연결 해제」를 누르면 기기에서 지워집니다.

## 파일이 오가는 곳

| 내용 | 위치 |
|---|---|
| 문제·프로그램 | 이 저장소(GitHub Pages) ↔ PC의 `기출문제 연습코너` 폴더 |
| 학습상태 JSON | `Park-hyojoon/tax-accounting-learning-sync`의 `sync/learning-state.json` |
| 오늘 학습기록 Markdown | 같은 저장소의 `records/날짜/분야-기기.md` (PC에서는 `또 틀렸다!/GitHub학습기록/records/`에도 복제됨) |
| 도우미 로그 | PC의 `또 틀렸다!/동기화도우미.log` |

각 분야 화면의 「오늘 학습기록 저장」은 AI 분석용 Markdown을 GitHub에 저장합니다. 홈의 JSON 백업은 수동 복원용입니다.

## 특별훈련 · 반복 약점

- ‘훈련 중 오답’에는 한국시간 2026년 9월 26일 이후 채점에서 틀렸거나 ‘틀렸어요 · 다시 연습’으로 표시한 문제가 한 번부터 모입니다. 이론·일반전표·매입매출전표·시간 훈련에 적용됩니다.
- 정답이나 ‘알고 있어요 · 통과’로 처리하면 다음 방문부터 빠지고, 다시 틀리면 돌아옵니다. 취소한 기록과 기준일 이전 오답 횟수는 포함하지 않습니다.
- ‘직접 제출 3회 이상’에서는 같은 문제·유사 유형·큰 개념의 반복 제출 기록을 따로 봅니다. 훈련 중 오답 횟수는 이 제출 건수에 합산하지 않습니다.
- 두 목록에 해당하는 문제는 ‘반복 약점에도 포함’으로 표시합니다. PC·모바일 학습기록을 동기화하면 각 기기에서 같은 기준으로 목록을 계산합니다.

## 매입매출전표 KcLep형 입력

- 문제에 부가가치세 포함금액·공급대가가 주어지면 공급가액 칸에 합계액을 입력하고 Enter를 눌러 공급가액과 부가세로 자동 분리할 수 있습니다. 공급가액이 제시된 문제는 10% 세액을 계산합니다.
- 분개 선택은 숫자키 `1` 현금, `2` 외상, `3` 혼합, `4` 카드로 바로 선택할 수 있습니다.
- 신용카드사·봉사료, 영세율구분, 불공제사유는 선택한 전표 유형에 해당할 때만 입력할 수 있습니다.

## 개념 정리

- 메뉴의 「개념 정리」에서 부가가치세 8개 단원과 확인 질문을 공부할 수 있습니다.
- 본문을 선택해 밑줄·형광펜·굵게 표시하고, 각 단원의 「내 말로 정리하기」에 메모를 씁니다.
- 표시와 메모는 해당 브라우저에 저장됩니다. 학습기록 동기화와 별도이므로 다른 기기로 옮길 때는 「표시·메모 백업」을 사용합니다.
- 기본 교재 PDF 또는 나의 표시·메모가 포함된 MD·TXT·인쇄/PDF를 내려받을 수 있습니다. TXT는 서식 없는 글자만 보존합니다.

## 동기화 문제가 생기면

- 「동기화」가 충돌을 알리면 PC와 GitHub에서 같은 파일의 같은 부분을 서로 다르게 고친 경우입니다. 양쪽 파일은 그대로 보존되며, AI에게 `기출문제 연습코너` 폴더의 충돌 정리를 요청하면 됩니다.
- 학습기록은 사용자가 「동기화」 또는 「오늘 학습기록 저장」을 눌렀을 때만 GitHub로 전송됩니다.
