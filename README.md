# 전산회계 1급 오답 훈련센터

전산회계 1급 시험에서 틀린 문제를 다시 훈련하기 위한 개인 학습용 웹페이지입니다.

## 모바일에서 사용하기

1. [오답 훈련센터 열기](https://park-hyojoon.github.io/tax-accounting-wrong-answer-center/)
2. 원하는 문제를 열어 답안을 입력하고 채점합니다.
3. 각 문제 화면의 `오늘 학습기록 저장`을 누르면 오늘 실제로 채점한 문제와 오늘의 답변 이력만 Markdown으로 저장됩니다.
4. GitHub를 연결했다면 기록은 공개 학습기록 저장소에 저장되고, 연결하지 않았다면 기기에 내려받습니다.
5. 훈련센터 첫 화면의 `학습상태 동기화`를 누르면 모바일과 PC의 서로 다른 채점 이력을 합친 뒤 같은 상태로 맞춥니다.

## 처음 한 번 GitHub 연결하기

학습기록은 별도의 공개 저장소 `Park-hyojoon/tax-accounting-learning-sync`에 보관합니다. Fine-grained 토큰을 만들 때 Selected repositories에서 이 저장소와 프로그램 저장소 `Park-hyojoon/tax-accounting-wrong-answer-center` 두 개만 선택하고 저장소 권한은 `Contents: Read and write`만 허용합니다. 토큰은 채팅에 보내거나 파일에 적지 말고 훈련센터의 비밀번호 입력칸에만 입력하세요.

토큰은 현재 브라우저 세션에만 남으므로 브라우저를 완전히 닫은 뒤에는 다시 입력해야 합니다.

## PC에 새 문제를 추가한 뒤

훈련센터 홈에서 `학습기록 + 새 문제 동기화`를 누르고 `기출문제 연습코너` 폴더를 선택합니다. 화면이 PC와 GitHub 중 최신 쪽과 변경할 파일을 보여주면 확인 후 진행합니다. PC가 최신이면 문제·채점 기준·센터 메뉴를 한 번의 GitHub 커밋으로 올리고, GitHub가 최신이면 지정된 핵심 파일만 PC에 적용합니다. 개인 기록 폴더와 `.git`은 동기화 대상이 아닙니다.

모바일에서는 프로그램 폴더를 바꿀 수 없으므로 `학습기록만 동기화`를 사용합니다. GitHub Pages의 문제 프로그램은 PC에서 올린 뒤 잠시 후 자동으로 최신판이 됩니다.

## 파일의 차이

- Markdown: 사람이 읽거나 GPT에게 전달하여 오답을 분석하는 학습 보고서
- JSON: 모바일과 PC 사이에서 통과 상태, 채점 이력과 오답 횟수를 이어가는 수동 백업 파일

학습기록은 사용자가 `오늘 학습기록 저장` 또는 `학습상태 동기화`를 눌렀을 때만 GitHub로 전송됩니다. 연결 실패 시 오늘의 Markdown은 기기에 저장되어 기록 손실을 막습니다.
