# 전산회계 1급 오답 훈련센터

전산회계 1급 시험에서 틀린 문제를 다시 훈련하기 위한 개인 학습용 웹페이지입니다.

## 모바일에서 사용하기

1. [오답 훈련센터 열기](https://park-hyojoon.github.io/tax-accounting-wrong-answer-center/)
2. 원하는 문제를 열어 답안을 입력하고 채점합니다.
3. 학습을 마치면 각 문제 화면에서 Markdown 학습기록을 저장합니다.
4. PC에서 진행 상태까지 이어가려면 훈련센터 첫 화면의 `학습상태 백업 파일 저장`을 누릅니다.
5. 저장된 JSON 파일을 PC로 보낸 뒤 `학습상태 백업 파일 선택`으로 불러옵니다.

## 파일의 차이

- Markdown: 사람이 읽거나 GPT에게 전달하여 오답을 분석하는 학습 보고서
- JSON: 모바일과 PC 사이에서 통과 상태, 채점 이력, 오답 횟수와 메모를 이어가는 복원 파일

학습기록은 사용자가 직접 저장할 때만 파일로 생성되며 GitHub로 자동 전송되지 않습니다.
