오늘의 오답훈련

이론·일반전표·결산·매입매출전표를 나누지 않고, 오늘 등록된 문제 중 아직 통과하거나 숨기지 않은 문제를 등록 순서대로 보여줍니다.

문제는 이 화면에서 자동으로 새로 만들지 않습니다. 원본 연습문제를 열어 푼 뒤 다시 돌아오면 기록이 반영됩니다.

가장 많이 틀리는 문제 유형 TOP 5

훈련에서 틀린 횟수와 오답으로 등록된 문제 수를 더해 순위를 매깁니다. 막대를 누르면 그 유형의 문제가 펼쳐지고, 「이 유형 풀기」를 누르면 통과한 문제까지 다시 풀 수 있습니다.

훈련에서 틀린 횟수오답으로 등록된 문제 수휴대전화 기록까지 합치려면 먼저 「동기화」를 누르세요.
여기서는 집계와 연결만 합니다. 자동으로 변형문제를 만들지 않으며, 더 연습하고 싶은 유형은 AI에게 요청할 수 있습니다.

Markdown 학습기록은 GPT 분석용이고, 진행 상태를 다른 기기에서 이어갈 때는 이곳의 JSON 백업 파일을 사용합니다.

GitHub 연결 (모바일은 처음 한 번만)

PC는 바탕화면의 「오답훈련센터 시작」으로 열면 동기화 도우미가 함께 켜지므로 토큰이 필요 없습니다. 모바일은 처음 한 번만 아래에 토큰을 넣고 「연결」을 누르면 이 기기에 기억되고, 그 뒤로는 위 메뉴의 「동기화」 한 번이면 됩니다.

Fine-grained 토큰 만들기 · Selected repositories에서 tax-accounting-learning-sync 저장소를 선택하고 Contents: Read and write만 허용하세요. 토큰은 HTML·백업 파일·GitHub 저장소에 기록하지 않습니다.

오답 훈련센터 · 「동기화」 또는 「오늘 학습기록 저장」을 누른 경우에만 GitHub로 기록을 보냅니다.
