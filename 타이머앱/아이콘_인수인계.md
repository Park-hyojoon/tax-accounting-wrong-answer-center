# 타이머 작업 표시줄 아이콘

## 창 디자인

창은 아이콘의 남색·코랄색을 사용한다. 상단에는 제목과 문제 초기화·단축키 설정 아이콘만 표시하며 시작 버튼은 사용자 요청으로 제거했다. 원형 문제 타이머는 둥근 진행선과 상태 표시, 시험 타이머는 남색 카드로 구성한다. 각 시간 표시를 누르면 시간 설정이 열린다. 두 타이머의 시작·중단은 공통 단축키로 조작하며, 현재 단축키를 하단에 표시한다. 시간 계산 및 작업 표시줄 고정 설정은 기존과 동일하다.

- `study-timer.png`: 새 원본 이미지. 내장 image_gen으로 생성.
- `study-timer.ico`: 원본의 투명도를 유지한 Windows 아이콘. 16, 20, 24, 32, 40, 48, 64, 128, 256px 포함.
- `kclep_timer.pyw`: 창 아이콘을 적용하고 창 표시 전에 고정용 속성을 설정.
- `windows_taskbar.py`: 기존 AppUserModelID를 유지하면서 RelaunchCommand, RelaunchDisplayNameResource, RelaunchIconResource, ID를 창에 함께 설정. 고정 시 pythonw.exe의 기본 아이콘 대신 타이머 아이콘과 스크립트 실행 경로를 사용.
- `verify_taskbar.py`: 숨겨진 Windows 창에서 실제 속성 읽기와 여러 크기 아이콘 불러오기를 검증. 검증 통과. 실제 작업 표시줄 고정 클릭은 사용자 확인 필요.

적용: 기존 고정 항목을 해제 → 실행 중인 타이머 종료 → 기존 `타이머_실행.cmd`로 실행 → 실행 중인 타이머를 작업 표시줄에 고정. 이미 만들어진 고정 항목의 캐시와 실행 대상은 앱 수정만으로 바뀌지 않음.
