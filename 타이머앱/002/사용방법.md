# 타이머 002 · 노란 스톱워치

`타이머002_실행.cmd`로 실행합니다. 기존 타이머는 먼저 종료해야 같은 전역 단축키를 사용할 수 있습니다.

- Ctrl+Space: 문제·시험 타이머 함께 시작 / 일시정지 / 재개
- Ctrl+Alt+R: 문제 타이머 초기화
- Ctrl+Alt+Shift+R: 시험 타이머 초기화
- Ctrl+,: 단축키 설정 창 열기. 설정 창에서 이 단축키도 변경할 수 있습니다.
- 원형 시계 클릭: 문제 시간 설정. 노란 영역은 설정 시간 대비 남은 비율이며, 시작 전에는 꽉 차 있습니다.
- 아래 숫자 클릭: 시험 시간 설정
- 위쪽 큰 꼭지 클릭: 문제 타이머 초기화
- 오른쪽 작은 꼭지 또는 우클릭: 단축키 설정
- 원형 시계에 마우스를 올리면 제목 표시줄에서 문제의 남은 분·초를 확인할 수 있습니다.

설정은 이 폴더의 timer-settings.json에 별도로 저장합니다. 최초 설정은 기존 버전에서 복사했습니다. 시간이 초과되면 주황색으로 표시하고 초과 시간을 계속 측정합니다.

창은 시작할 때와 사용 중 1초 간격으로 현재 모니터의 작업 영역을 확인합니다. 작업 표시줄이나 화면 경계 밖으로 내려가면 창 전체가 보이는 위치로 올립니다. 창을 최소화했을 때는 움직이지 않습니다.

## 개발 인수인계

timer002.pyw가 화면·클릭 영역을 담당하고 timer_core.py의 기존 시간 계산·단축키·설정 기능을 재사용합니다. windows_taskbar.py는 002 전용 AppUserModelID와 아이콘 및 재실행 경로를 설정합니다.

build_artwork.py는 네이티브 도형을 4배 크기로 그린 후 LANCZOS 축소해 frames/의 182개 PNG, timer002.ico, preview.png를 만듭니다. 빌드에만 Pillow가 필요하며 프로그램 실행에는 필요하지 않습니다. 실행 중 최대 16장만 캐시합니다. frames 폴더를 포함해 이 폴더 전체를 함께 보관하세요.

검증: 구문, 타이머 공통 시작·정지, 렌더 이미지 확인. 이 작업 환경의 Tcl 문제로 실제 Tk 창 실행 검증은 하지 못했습니다.
